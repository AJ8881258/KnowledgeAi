# 前端任务书：阶段 14 部署与运维收尾

本任务书是前端会话的固定入口。后续每个阶段都复用本文件，由文档会话实时更新当前任务。前端会话必须先阅读 `AGENTS.md`、`doc/STAGE_PLAN.md`、`doc/PROJECT.md`、`doc/API.md` 和本文件。

## 当前目标

阶段 14：部署与运维。

目标不是继续新增业务页面，而是让当前前端在本地复现、生产构建、预览部署和验收说明上更稳定、更清晰。重点整理环境变量、构建产物、部署说明、README 前端部分和必要的脚本/配置。

## 本轮任务

1. 检查前端环境变量和 Vite 配置：
   - 明确本地开发、生产构建、预览环境使用哪些变量。
   - 如果需要新增 `.env.example` 或补齐现有示例，只写占位值，不写真实密钥。
   - 确认前端仍通过 axios wrapper 和 Vite proxy/后端 base path 调用接口，不写死个人机器地址。
2. 检查生产构建与预览：
   - 确认 `pnpm build` 可生成 `dist/`。
   - 确认 `pnpm preview` 的使用说明准确。
   - 如有必要，补充前端静态部署说明，例如 Nginx、静态托管或反向代理注意事项。
3. 更新 README 或相关文档中的前端启动步骤：
   - 安装依赖。
   - 本地开发启动。
   - 生产构建。
   - 预览构建产物。
   - 常见问题，例如后端未启动、登录 401、代理地址不对。
4. 检查用户验收路径说明：
   - 登录。
   - Settings 配置模型。
   - 创建/查看知识库。
   - 上传文档并检索。
   - Chat 发送问题。
   - 未读会话、今日交谈次数。
5. 不新增 mock-only 数据，不恢复旧 mock 登录或 mock Chat。
6. 不新增直接 `fetch`，不新增组件级 `localStorage`。
7. 不主动使用 Chrome、Browser、Playwright、截图或浏览器验收工具，除非用户明确要求。

## UI 与交付要求

- 阶段 14 默认不做 UI 大改。
- 只修复会影响部署、启动、构建或验收的前端问题。
- 如果发现明显影响演示的 UI 文案或布局问题，先报告给用户或文档会话确认范围。
- 保持 shadcn/radix-sera、Lucide、Tailwind 和现有视觉风格。

## 建议涉及文件

可能修改：

- `README.md`
- `.env.example` 或前端环境变量示例文件
- `vite.config.ts`
- `package.json`
- `doc/PROJECT.md`
- 与前端部署说明相关的文档

不应修改：

- 与阶段 14 无关的业务页面逻辑。
- 后端 Java 代码。
- 真实密钥、真实 API Key、生产数据库密码。

## 验收命令

```powershell
pnpm build
```

如修改了前端代码或配置，运行目标 ESLint：

```powershell
pnpm eslint src
```

如果全量 `pnpm lint` 或 `pnpm eslint src` 仍有历史问题，只说明哪些不是本次修改范围。

## 手动验收说明

完成后给用户一份简短可执行步骤：

1. 如何启动数据库和后端。
2. 如何启动前端开发服务。
3. 如何构建并预览前端生产产物。
4. 登录后依次验证哪些页面。
5. 如果模型配置或 Chat 失败，应先检查哪些环境变量和 Settings 配置。

## 完成后输出

完成后请输出：

1. 修改了哪些文件。
2. 前端本地开发和生产构建流程如何变化。
3. 是否新增或修改环境变量示例。
4. 是否修改 API base/proxy 相关配置。
5. 运行了哪些校验命令和结果。
6. 还需要用户手动验收的路径和步骤。
