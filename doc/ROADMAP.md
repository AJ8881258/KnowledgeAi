# 开发路线

## 当前状态

当前已经完成后端基础能力：

- Spring Boot 后端项目。
- PostgreSQL 本地数据库。
- Flyway 初始化表结构。
- 知识库查询接口。
- 知识库创建、修改、删除接口。
- 知识库接口按当前登录用户隔离。
- 知识库已支持精选标记 `featured` 和主题色字段 `themeId`。
- 用户注册接口。
- 用户登录接口。
- 登录成功返回 JWT `accessToken`。
- Spring Security 基础放行规则。

## 已完成阶段

### Login 闭环

- 前端登录页调用 `POST /api/auth/login`。
- 前端注册入口调用 `POST /api/auth/register`。
- 找回密码调用 `POST /api/auth/reset-password`。
- 登录成功后保存用户信息和 `accessToken`。
- 前端业务请求会自动携带 `Authorization`。
- 未登录访问主应用会跳转登录页。

## 下一步优先级

### 1. 知识库 CRUD

目标：

- 前端知识库页面调用真实接口，不再依赖 mock 数据。
- 新建、编辑、删除操作调用后端接口。
- 详情页路由参数按后端 `id` 处理。

完成标准：

- 前端知识库页面加载后端知识库列表。
- 用户可以在前端创建、编辑、删除自己的知识库。
- 不同用户只能看到自己的知识库。后端部分已完成，前端仍需接入。

### 2. 登录态完善

目标：

- 后端根据 token 判断当前用户。
- 新增 `GET /api/auth/me`。
- 继续完善刷新后的当前用户确认能力。

完成标准：

- 刷新页面后仍能识别登录状态。
- 未登录访问受保护接口会返回认证错误。

### 3. 文档上传

目标：

- 为知识库上传 TXT / Markdown 文档。
- 保存文档元信息。
- 展示文档列表和处理状态。

完成标准：

- 用户能在某个知识库下上传文档。
- 前端能看到文档状态。

### 4. 文档解析和切片

目标：

- 读取上传文档文本。
- 按规则切分 chunk。
- 保存 chunk 到数据库。

完成标准：

- 能查看某个文档的 chunk 列表。
- 空文件、过大文件、非支持类型有明确错误。

### 5. RAG 检索问答

目标：

- 为 chunk 生成 embedding。
- 使用 pgvector 检索相似内容。
- 将检索结果放入 Prompt。
- 调用大模型生成回答。
- 保存会话和消息。

完成标准：

- 用户可以在知识库内提问。
- 回答基于上传资料。
- 回答能展示引用来源。

### 6. 项目交付文档

目标：

- 完善 README。
- 补充启动说明。
- 补充演示账号。
- 补充架构图和 RAG 流程图。

完成标准：

- 新人可以按 README 启动项目。
- 面试时可以清楚说明项目架构和核心流程。

## 当前不优先做

- Spring Cloud。
- Kubernetes。
- 消息队列。
- 多服务独立数据库。
- 复杂权限系统。
- PDF OCR。
- Agent 工作流。

这些能力可以作为后续扩展，但不应该阻塞当前 MVP。
