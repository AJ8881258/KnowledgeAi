# 开发路线

详细阶段、状态和验收标准以 [STAGE_PLAN.md](STAGE_PLAN.md) 为准。本文件只保留简版路线，方便快速查看下一步开发顺序。

## 当前状态

已完成：

- 前端静态原型。
- Spring Boot 后端基础设施。
- 注册、登录、JWT、重置密码和前端登录态。
- 知识库 CRUD、用户隔离、精选标记和主题色字段。
- 文档上传、解析、切片和索引状态。

当前下一阶段：

- 阶段 5：文档检索 MVP。

## 后续顺序

1. 文档检索 MVP
   - 基于 `document_chunks` 做知识库内关键词检索。
   - 第一版只用 PostgreSQL 普通关键词匹配。
   - 不接大模型，不上 embedding，不上 pgvector。
   - 前端只做“检索测试区”。

2. RAG 问答 MVP
   - 使用检索结果构造 prompt。
   - 调用大模型生成回答。
   - 返回答案和引用来源。
   - 保存会话和消息。

3. 前端体验完善
   - 清理剩余 mock 文案。
   - 统一加载、错误、空状态、删除确认、上传状态。
   - 优化知识库、文档、检索、问答之间的流程。

4. 项目交付整理
   - 完善 README。
   - 补充启动说明、演示账号、架构说明和 RAG 流程说明。
   - 保证新人可以按文档启动和演示项目。

## 当前不优先做

- Spring Cloud。
- Kubernetes。
- 消息队列。
- 多服务独立数据库。
- 复杂权限系统。
- PDF OCR。
- Agent 工作流。

这些能力可以作为后续扩展，但不应该阻塞当前 MVP。
