## 已完成阶段说明

- 文档检索 MVP
   - 基于 `document_chunks` 做知识库内关键词检索。
   - 第一版只用 PostgreSQL 普通关键词匹配。
   - 不接大模型，不上 embedding，不上 pgvector。
   - 后端提供 `POST /api/knowledge-bases/{knowledgeBaseId}/search`，只检索当前用户自己的 `INDEXED` 文档 chunks。
   - 前端在知识库详情页提供“检索测试区”，用于输入关键词、限制结果数量，并展示命中文档、chunk 序号、分数和片段内容。
   - 已通过 `pnpm build` 和后端 Maven 测试。

## 当前不优先做

- Spring Cloud。
- Kubernetes。
- 消息队列。
- 多服务独立数据库。
- 复杂权限系统。
- PDF OCR。
- Agent 工作流。

这些能力可以作为后续扩展，但不应该阻塞当前 MVP。
