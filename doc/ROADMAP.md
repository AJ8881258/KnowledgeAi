# 开发路线

## 当前状态

当前已经完成后端基础能力：

- Spring Boot 后端项目。
- PostgreSQL 本地数据库。
- Flyway 初始化表结构。
- 知识库查询接口。
- 用户注册接口。
- 用户登录接口。
- Spring Security 基础放行规则。

## 下一步优先级

### 1. 前端登录和注册接后端

目标：

- 前端登录页调用 `POST /api/auth/login`。
- 前端注册入口调用 `POST /api/auth/register`。
- 登录失败时显示错误提示。
- 登录成功后保存用户信息并跳转首页。

完成标准：

- `admin / admin` 可以从前端登录。
- 新注册用户可以从前端登录。
- 错误密码不会跳转。

### 2. 登录态和 JWT

目标：

- 登录成功后后端签发 token。
- 前端请求业务接口时携带 token。
- 后端根据 token 判断当前用户。
- 新增 `GET /api/auth/me`。

完成标准：

- 刷新页面后仍能识别登录状态。
- 未登录访问受保护接口会返回认证错误。

### 3. 知识库 CRUD

目标：

- 创建知识库。
- 编辑知识库名称和描述。
- 删除知识库。
- 查询当前用户自己的知识库。

完成标准：

- 前端知识库页面不再依赖 mock 数据。
- 不同用户只能看到自己的知识库。

### 4. 文档上传

目标：

- 为知识库上传 TXT / Markdown 文档。
- 保存文档元信息。
- 展示文档列表和处理状态。

完成标准：

- 用户能在某个知识库下上传文档。
- 前端能看到文档状态。

### 5. 文档解析和切片

目标：

- 读取上传文档文本。
- 按规则切分 chunk。
- 保存 chunk 到数据库。

完成标准：

- 能查看某个文档的 chunk 列表。
- 空文件、过大文件、非支持类型有明确错误。

### 6. RAG 检索问答

目标：

- 为 chunk 生成 embedding。
- 使用 pgvector 检索相似内容。
- 将检索结果放入 Prompt。
- 调用大模型生成回答。
- 保存会话和消息。

完成标准：

- 用户可以在知识库内提问。
- 回答基于上传资料。
- 回答能展示引用来源。

### 7. 项目交付文档

目标：

- 完善 README。
- 补充启动说明。
- 补充演示账号。
- 补充架构图和 RAG 流程图。

完成标准：

- 新人可以按 README 启动项目。
- 面试时可以清楚说明项目架构和核心流程。

## 当前不优先做

- Spring Cloud。
- Kubernetes。
- 消息队列。
- 多服务独立数据库。
- 复杂权限系统。
- PDF OCR。
- Agent 工作流。

这些能力可以作为后续扩展，但不应该阻塞当前 MVP。
